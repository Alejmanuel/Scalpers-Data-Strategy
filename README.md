# Scalpers Data Strategy

Data Strategy project developed for Scalpers, focused on designing a data-driven strategy to improve business decision-making through Business Intelligence, data governance and analytics.

# Overview

This project presents a comprehensive data strategy for Scalpers, identifying business opportunities, defining governance practices and proposing analytical solutions to support strategic decision-making.

The project includes:

- Business analysis
- Data strategy definition
- Data governance
- KPI identification
- Business Intelligence roadmap
- Data-driven decision making
